# Chow Use Case Examples

This folder contains example projects demonstrating how developers can implement Chow for a variety of use cases.

**Note:** These examples are not intended to be production-ready. Some projects may not use the latest features or patterns.

## Projects

- [`Chow.Examples.Blazor/Chow.Examples.Blazor.csproj`](Chow.Examples.Blazor/Chow.Examples.Blazor.csproj) — A Blazor WebAssembly code editor for writing and running Chow source in the browser. Shows capturing `print` output, surfacing Chow exceptions, and overriding the `input` built-in with a native browser prompt popup.
